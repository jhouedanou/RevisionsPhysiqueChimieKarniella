Leçon 1 : INITIATION À L'UTILISATION D'UN ORDINATEUR
I. Définition des notions
1°) La notion d'informatique : L'informatique est la science qui permet de traiter automatiquement des informations.
2°) La notion de système informatique : Le système informatique est un ensemble de composants (logiciels et matériels) qui fonctionnent ensemble et permettent de traiter les informations.
II. Les différentes parties d'un ordinateur
Un ordinateur se compose de deux grandes parties.
1°) La partie matérielle : C'est la partie physique de l'ordinateur, on l'appelle aussi hardware. Elle est composée de l'unité centrale et des périphériques. Parmi les périphériques, nous avons le clavier, la souris (périphériques d'entrée), l'écran, l'imprimante (périphériques de sortie), la clé USB (périphérique de stockage).
2°) La partie logicielle : On y retrouve deux catégories de logiciels, à savoir :
– les logiciels d'application : répondre à un besoin précis ;
– les systèmes d'exploitation, qui permettent de gérer tous les composants (Windows, Mac OS, Linux).
La partie logicielle porte le nom de software.
III. Démarrer et éteindre l'ordinateur (cas d'un ordinateur de bureau)
1°) Le démarrage : Pour démarrer un ordinateur de bureau, il faut s'assurer que tous les composants sont parfaitement connectés à l'unité centrale. Par la suite, on branche l'écran et l'unité centrale sur une prise de courant électrique et on fait une pression sur le bouton d'allumage. À la fin du démarrage, l'écran affiche le « Bureau ».
2°) Éteindre un ordinateur : Il existe plusieurs possibilités pour éteindre un ordinateur.
• À partir du menu « Démarrer », représenté par le symbole de Windows : on fait un clic gauche sur le symbole, on choisit l'option « Marche/Arrêt » (⏻), puis le bouton « Arrêter ».
• À partir d'un raccourci clavier : en faisant la combinaison ALT + F4, nous ouvrons une boîte de dialogue et nous validons l'option « Arrêter » par la touche « Entrée ».
• À partir des paramètres du système :
– définir dans les paramètres que l'ordinateur s'éteint une fois l'écran fermé (seulement pour les ordinateurs portables) ;
– définir les paramètres de sorte que l'ordinateur s'éteigne lorsqu'on fait une pression sur le bouton d'allumage.

Leçon 2 : ÉLÉMENTS DE PERFORMANCE D'UN ORDINATEUR
I. Indicateurs de performance
Pour déterminer la performance d'un ordinateur, on se base sur plusieurs éléments tels que : le disque dur, la mémoire RAM, le processeur.
1°) Le processeur : C'est le composant essentiel de l'ordinateur, car c'est lui qui traite toutes les commandes passées par l'utilisateur. La fréquence de travail s'exprime en hertz (Hz).
2°) La mémoire RAM : C'est la mémoire de travail. La RAM (Random Access Memory) est l'espace dans lequel toutes les applications sont chargées afin d'être utilisées. Elle s'exprime en octets.
