Séance 1 : Comment faire un exposé oral ?

Définition
L'exposé oral est un discours généralement oral dans lequel l'on présente
un plan [?] donné des informations et son point de vue personnel sur un
thème ou sujet donné. Le point de vue sur le thème est l'exposé [?] de ce
qu'il pense sur le thème. Le thème peut être un comportement, un phénomène.

Les caractéristiques de l'exposé oral
Exprimer un point de vue dans un exposé oral consiste à discuter ou faire un
débat. Pour réussir l'exposé, il faut observer deux phases.

1. La phase de préparation de l'exposé
Il s'agit de faire des recherches pour recueillir les informations
nécessaires pour l'exposé. Organiser le travail comme on le ferait dans un
discours écrit : une introduction, un développement, une conclusion.

2. La phase de **présentation** de l'exposé
Pour présenter un exposé oral, il faut :
- rappeler le ou les points de vue **opposés au sien** ;
- utiliser les phrases déclaratives.
