Leçon 8 - Addition de nombres relatifs

Somme de Nombres de Mêmes Signes

✓ Règle pour les nombres de mêmes signes

Pour additionner deux nombres relatifs de même signe :

  • On additionne leurs distances à zéro
  • On garde le signe commun

💡 Exemples - Deux nombres positifs

(+5) + (+3)

Distance à zéro : 5 et 3

Somme des distances : 5 + 3 = 8

Signe commun : +

Résultat : (+5) + (+3) = +8

💡 Exemples - Deux nombres négatifs

(-7) + (-4)

Distance à zéro : 7 et 4

Somme des distances : 7 + 4 = 11

Signe commun : -

Résultat : (-7) + (-4) = -11

💡 Autres exemples

  • (+2,5) + (+1,3) = +3,8
  • (-6) + (-9) = -15
  • (+10) + (+5) = +15
  • (-0,4) + (-0,7) = -1,1
💡 À retenir :
• Même signe → on additionne et on garde le signe
• Positif + Positif = Positif (de plus en plus grand)
• Négatif + Négatif = Négatif (de plus en plus petit)

Somme de Nombres de Signes Contraires

✓ Règle pour les nombres de signes contraires

Pour additionner deux nombres relatifs de signes contraires :

  • On calcule la différence de leurs distances à zéro
  • On donne au résultat le signe du nombre qui a la plus grande distance à zéro

💡 Exemple 1

(+8) + (-3)

Distance à zéro : 8 et 3

Différence : 8 - 3 = 5

Plus grande distance : 8 (nombre positif)

Résultat : (+8) + (-3) = +5

💡 Exemple 2

(-9) + (+4)

Distance à zéro : 9 et 4

Différence : 9 - 4 = 5

Plus grande distance : 9 (nombre négatif)

Résultat : (-9) + (+4) = -5

💡 Exemple 3 - Cas particulier

(+7) + (-7)

Distance à zéro : 7 et 7

Différence : 7 - 7 = 0

Résultat : (+7) + (-7) = 0

Deux opposés s'annulent !

💡 Autres exemples

  • (+15) + (-8) = +7
  • (-12) + (+5) = -7
  • (+3,5) + (-1,2) = +2,3
  • (-6) + (+6) = 0
💡 À retenir :
• Signes contraires → on soustrait et on prend le signe du plus grand
• Deux opposés donnent toujours 0
• Astuce : pense à un déplacement sur la droite graduée

✏️ Exercices - Somme de Nombres Relatifs

Entraîne-toi ! Cherche d'abord la réponse sur ton cahier, puis affiche la correction. 🐴

✓ Rappel des deux règles

Mêmes signes : on additionne les distances à zéro, on garde le signe commun.

Signes contraires : on soustrait les distances à zéro, on prend le signe du nombre le plus éloigné de zéro.

🌾 Exercice 1 - Mêmes signes

Calcule les sommes suivantes :

  1. (+12) + (+7) = ?
  2. (-6) + (-8) = ?
  3. (+3,5) + (+2,5) = ?
  4. (-1,4) + (-2,3) = ?
Correction :
1. (+12) + (+7) = +19 — on additionne 12 + 7 = 19, signe commun +
2. (-6) + (-8) = -14 — on additionne 6 + 8 = 14, signe commun -
3. (+3,5) + (+2,5) = +6 — on additionne 3,5 + 2,5 = 6, signe commun +
4. (-1,4) + (-2,3) = -3,7 — on additionne 1,4 + 2,3 = 3,7, signe commun -

🌾 Exercice 2 - Signes contraires

Calcule les sommes suivantes :

  1. (+14) + (-9) = ?
  2. (-11) + (+4) = ?
  3. (+2,8) + (-5,3) = ?
  4. (-7,5) + (+7,5) = ?
Correction :
1. (+14) + (-9) = +5 — différence 14 - 9 = 5, le plus éloigné de zéro est +14 donc signe +
2. (-11) + (+4) = -7 — différence 11 - 4 = 7, le plus éloigné de zéro est -11 donc signe -
3. (+2,8) + (-5,3) = -2,5 — différence 5,3 - 2,8 = 2,5, le plus éloigné de zéro est -5,3 donc signe -
4. (-7,5) + (+7,5) = 0 — ce sont deux opposés, ils s'annulent

🌾 Exercice 3 - Problèmes concrets

  1. Le matin il fait -3 °C. Dans la journée la température monte de 9 °C. Quelle température fait-il ?
  2. Un cheval part d'un point A. Il avance de 12 m, puis recule de 5 m. À quelle distance de A se trouve-t-il ?
  3. Un ascenseur est au niveau -2. Il descend encore de 3 niveaux. À quel niveau arrive-t-il ?
  4. Karniella avait 15 points. Elle perd 20 points, puis en gagne 8. Combien a-t-elle de points ?
Correction :
1. (-3) + (+9) = +6 °C
2. (+12) + (-5) = +7 m, il est à 7 m devant A
3. (-2) + (-3) = -5, il arrive au niveau -5
4. (+15) + (-20) + (+8) = (-5) + (+8) = +3 points

🌾 Exercice 4 - Trouve le nombre manquant

  1. (+8) + ... = +3
  2. (-4) + ... = -10
  3. ... + (-6) = +2
  4. (-9) + ... = 0
Correction :
1. -5 car (+8) + (-5) = +3
2. -6 car (-4) + (-6) = -10
3. +8 car (+8) + (-6) = +2
4. +9 car (-9) + (+9) = 0, c'est l'opposé de -9
💡 Astuce :
Pour vérifier, imagine un déplacement sur la droite graduée : un nombre positif fait avancer vers la droite, un nombre négatif fait reculer vers la gauche. 🏇
