Radical, préfixe, suffixe et famille de mots

Séance 1 : La formation des mots par dérivation

1. Définition

📘 Définition

La dérivation est la formation d'un mot nouveau en ajoutant un préfixe ou un suffixe à un radical.

Le motCe que c'estExemple
le radicalLa partie du mot qui porte le sens.terre, enterrer
le préfixeIl se place avant le radical.refaire
le suffixeIl se place après le radical.chanteur

📘 La famille de mots

Les mots formés sur le même radical sont de la même famille.
Exemple : terre, terrain, terrasse, enterrer, déterrer.

🐴 Comme un train

Le radical est le wagon du milieu. Le préfixe s'accroche devant, le suffixe derrière.

💡 Exemples pour les exercices

Exemple 1

Question : Dans « refaire », quel est le préfixe ?

Réponse : re
re + faire : « re » est le préfixe, « faire » est le radical.

Question : Dans « chanteur », quel est le suffixe ?

Réponse : eur
chant + eur : « chant » est le radical, « eur » est le suffixe.

Exemple 2

Question : Quel mot n'est PAS de la famille de « terre » ?

Réponse : terrible
Terrible ne parle pas de la terre : il n'est pas de la même famille.

2. Formation par dérivation

Il y a trois façons de former un mot dérivé.

a) Avec un préfixe

préfixe + radical. Le préfixe change le sens du mot. Il ne change pas sa classe : faire et refaire sont deux verbes.

PréfixeSon sensExemples
re-de nouveaurelire, refaire
dé-le contrairedéfaire, déboucher
in-, im-, il-, ir-le contraireinjuste, impossible, illisible, irrégulier
pré-avantprévoir, préhistoire

⚠️ L'orthographe du préfixe « in »

  • Devant m, b, p : im. impossible, imbattable, immangeable.
  • Devant l : il. illisible.
  • Devant r : ir. irrégulier.

b) Avec un suffixe

radical + suffixe. Le suffixe change souvent la classe du mot : lent est un adjectif, lentement est un adverbe.

SuffixeSon sensExemples
-eur, -eusecelui ou celle qui faitchanteur, vendeuse
-agel'actionlavage, collage
-ettepetitfillette, maisonnette
-mentla manièrelentement, doucement
-ablequ'on peut…lavable, mangeable

c) Avec un préfixe et un suffixe

préfixe + radical + suffixe.
Exemples : dé + coll + age = décollage ; im + mange + able = immangeable.

💡 Exemples pour les exercices

Exemple 3

Question : Que veut dire le préfixe « re » dans « relire » ?

Réponse : de nouveau
Relire : lire de nouveau.

Question : Quel est le contraire de « possible », formé avec un préfixe ?

Réponse : impossible
Devant m, b, p, le préfixe « in » s'écrit « im » : impossible.

Exemple 4

Question : Le suffixe « ette » dans « fillette » veut dire…

Réponse : petit
Une fillette : une petite fille.

Question : Quel mot est formé avec un préfixe ET un suffixe ?

Réponse : décollage
dé + coll + age : un préfixe, un radical, un suffixe.

Exercices

Cherche d'abord seule. Ensuite, ouvre la correction.

Exercice 1 — Coupe le mot

iAide-mémoire : regarde l'exemple 1, dans « 1. Définition ».

Pour chaque mot, donne le radical. Dis si l'autre partie est un préfixe ou un suffixe.

  1. revenir
  2. danseur
  3. défaire
  4. lavage
Voir la correction
  1. Radical : venir. « re » est un préfixe.
  2. Radical : dans. « eur » est un suffixe.
  3. Radical : faire. « dé » est un préfixe.
  4. Radical : lav. « age » est un suffixe.

Exercice 2 — Chasse l'intrus

iAide-mémoire : regarde l'exemple 2, dans « 1. Définition ».

Dans chaque liste, un mot n'est pas de la famille. Trouve-le.

  1. dent, dentiste, dentifrice, danser
  2. lait, laitier, laitage, laid
  3. chant, chanteur, chanson, chance
Voir la correction
  1. danser : il ne parle pas des dents.
  2. laid : il ne parle pas du lait.
  3. chance : il ne parle pas du chant.

Exercice 3 — Trouve le contraire

iAide-mémoire : regarde l'exemple 3, dans « 2. Formation par dérivation ».

Forme le contraire avec un préfixe : dé-, in-, im-, il- ou ir-.

  1. utile
  2. prudent
  3. monter
  4. logique
  5. responsable
Voir la correction
  1. inutile
  2. imprudent (devant p : im)
  3. démonter
  4. illogique (devant l : il)
  5. irresponsable (devant r : ir)

Exercice 4 — Ajoute un suffixe

iAide-mémoire : regarde l'exemple 4, dans « 2. Formation par dérivation ».

Forme un mot nouveau avec le suffixe donné.

  1. vendre + eur
  2. camion + ette
  3. rapide + ment
  4. jardin + age
Voir la correction
  1. un vendeur
  2. une camionnette
  3. rapidement
  4. le jardinage
