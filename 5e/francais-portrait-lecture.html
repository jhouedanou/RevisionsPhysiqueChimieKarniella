Exploiter un texte

Exploiter un texte, c'est le relire pour étudier ses mots (le vocabulaire) et ses outils (la grammaire).

Un portrait pour t'entraîner

📖 Tante Affoué

Tante Affoué est une femme grande et mince. Elle a un visage rond, des yeux noirs et vifs, et un large sourire. Ses cheveux tressés tombent sur ses épaules. Elle porte toujours un pagne coloré et des sandales en cuir.

Tante Affoué est généreuse et patiente. Au marché, elle parle d'une voix douce. Elle semble calme, mais elle est très courageuse : elle se lève avant le soleil. Tout le quartier l'aime.

Les deux parties du portrait

PartieCe qu'elle montreDans le texte
Le portrait physiqueCe qu'on voit : le corps, le visage, les vêtements.Le premier paragraphe
Le portrait moralLe caractère : les qualités et les défauts.Le deuxième paragraphe

💡 Exemples pour les exercices

Exemple 1

Question : « Elle a un visage rond » : quel portrait ?

Réponse : physique
Le visage se voit : c'est le portrait physique.

Question : « Elle est généreuse » : quel portrait ?

Réponse : moral
La générosité est une qualité du caractère : c'est le portrait moral.

MotSens

Synonymes et contraires

Un synonyme a presque le même sens : mince et maigre. Un contraire a le sens opposé : généreux et avare.

🐴 Le mot juste

Évite « beau » et « gentil ». Choisis un mot précis : élancé, souriant, généreux.

💡 Exemples pour les exercices

Exemple 2

Question : Quel mot est une qualité ?

Réponse : honnête
Honnête est une qualité. Avare, menteur et paresseux sont des défauts.

Question : Quel est le contraire de « généreux » ?

Réponse : avare
Le généreux donne, l'avare garde tout.

2. Grammaire

Un portrait emploie trois outils.

Les adjectifs qualificatifs

L'adjectif qualificatif dit comment est le personnage. Il s'accorde avec le nom.
Dans le texte : un visage rond, des yeux noirs, une voix douce.

Les verbes d'état

Les verbes d'état relient le personnage à une qualité : être, sembler, paraître, avoir l'air.
Dans le texte : Tante Affoué est généreuse. Elle semble calme.

On emploie aussi avoir et porter : elle a un visage rond, elle porte un pagne.

Le présent de description

Le portrait est souvent au présent : il montre le personnage tel qu'il est.
Dans le texte : elle a, elle porte, elle parle.

🐴 Déjà vu

L'accord de l'adjectif est dans ta leçon de grammaire : Le groupe nominal : genre et nombre.

💡 Exemples pour les exercices

Exemple 3

Question : Dans « des yeux noirs », quel mot est l'adjectif ?

Réponse : noirs
Noirs dit comment sont les yeux. Il est au masculin pluriel, comme « yeux ».

Exemple 4

Question : Quel verbe est un verbe d'état ?

Réponse : sembler
Sembler relie le personnage à une qualité : elle semble calme.

Question : À quel temps est « elle porte un pagne » ?

Réponse : présent
Le portrait est au présent de description.

Exercices

Cherche d'abord seule. Ensuite, vérifie.

Exercice 1 — Physique ou moral ?

iAide-mémoire : regarde l'exemple 1, dans « Le texte ».

Écris « physique » ou « moral ».

  1. Il a de larges épaules : …
  2. Elle est toujours polie : …
  3. Ses cheveux sont gris : …
  4. Il déteste le mensonge : …
Voir la correction
  1. physique : les épaules se voient.
  2. moral : la politesse est une qualité.
  3. physique : les cheveux se voient.
  4. moral : c'est son caractère.

Exercice 2 — Trouve le contraire

iAide-mémoire : regarde l'exemple 2, dans « 1. Vocabulaire ».

  1. patient → …
  2. courageux → …
  3. grand → …
  4. honnête → …
Voir la correction
  1. impatient
  2. peureux
  3. petit
  4. menteur

Exercice 3 — Relève l'adjectif

iAide-mémoire : regarde l'exemple 3, dans « 2. Grammaire ».

Écris l'adjectif qualificatif de chaque groupe.

  1. un large sourire : …
  2. des cheveux tressés : …
  3. un pagne coloré : …
  4. une femme mince : …
Voir la correction
  1. large
  2. tressés
  3. coloré
  4. mince

Exercice 4 — Accorde l'adjectif

iAide-mémoire : regarde l'exemple 3, dans « 2. Grammaire ».

  1. Mon oncle a des mains (fort) ….
  2. Ma voisine est (souriant) ….
  3. Il a des yeux (brillant) ….
  4. Elle porte une robe (bleu) ….
Voir la correction
  1. des mains fortes : féminin pluriel.
  2. Ma voisine est souriante : féminin singulier.
  3. des yeux brillants : masculin pluriel.
  4. une robe bleue : féminin singulier.

Exercice 5 — Le verbe du portrait

iAide-mémoire : regarde l'exemple 4, dans « 2. Grammaire ».

Complète au présent avec : est, a, porte, semble.

  1. Mon grand-père … une barbe blanche.
  2. Il … un grand boubou.
  3. Il … très sage.
  4. Aujourd'hui, il … fatigué, mais il sourit.
Voir la correction
  1. Mon grand-père a une barbe blanche.
  2. Il porte un grand boubou.
  3. Il est très sage.
  4. Aujourd'hui, il semble fatigué, mais il sourit.
