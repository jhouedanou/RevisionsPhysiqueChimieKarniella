Des nombres avec un signe : présentation et notation

Thème : Calculs algébriques
Leçon : Nombres décimaux relatifs

I. Nombres décimaux relatifs

1. Présentation et notation

📘 Définition

Les nombres décimaux relatifs sont des nombres entiers naturels ou des nombres décimaux précédés du signe − (moins) ou + (plus).

💡 Exemples

  • 28 est un nombre décimal relatif positif : on le note +28 ou 28.
  • −6 ; −3,5 sont des nombres décimaux relatifs négatifs.
  • +3,12 est un nombre décimal relatif positif.
  • −3,1 est un nombre décimal relatif négatif.

Un nombre décimal relatif est un nombre qui peut s'écrire avec un nombre fini de chiffres après la virgule.

💡 Exemple

+2,5 ; −1,7 ; −3 ; +23 ; −13 sont des nombres décimaux relatifs.

Notation

  • L'ensemble des nombres décimaux relatifs se note 𝔻.
  • L'ensemble des nombres décimaux relatifs positifs se note 𝔻⁺.
  • L'ensemble des nombres décimaux relatifs négatifs se note 𝔻⁻.

💡 Exemples

… (à recopier de ton cahier)

0 ∈ 𝔻 ; 0 ∈ 𝔻⁺ ; 0 ∈ 𝔻⁻

🐴 Pour bien retenir

Signe + → positif. On peut ne pas l'écrire : +28 = 28.
Signe − → négatif. On l'écrit toujours : −6 n'est pas 6.

✏️ À vérifier dans ton cahier

  • Les nombres des exemples : +2,5 ; −1,7 ; −3 ; +23 ; −13 ?
  • Le mot « fini » dans « un nombre fini de chiffres après la virgule ».
  • Les exemples écrits après la notation, avant « 0 ∈ 𝔻 ».
  • La fin de la leçon, après « 0 ∈ 𝔻⁻ ».

I. Présentation

🌡️ La situation

Le matin, le thermomètre de la cuisine d'Adja indique 25 degrés. Dans le congélateur, il indique 18 degrés au-dessous de zéro. Comment écrire ces deux températures avec des nombres ?

Cuisine : 25. Congélateur : on est au-dessous de zéro, donc on écrit −18, avec le signe moins.

📘 Définition

Un nombre décimal relatif est un nombre décimal qui porte un signe :

  • le signe + pour un nombre positif : +25 ; +3,5 ; +100 ;
  • le signe − pour un nombre négatif : −18 ; −0,5 ; −7.

Le nombre 0 est à la fois positif et négatif : il n'a pas de signe.

Où rencontre-t-on des nombres négatifs ?

SituationExemple
La température −18 °C dans le congélateur, +30 °C à Abidjan l'après-midi.
L'altitude Le sommet du mont Nimba est à +1 752 m ; un plongeur à −10 m est sous la mer.
L'argent +5 000 F : on a gagné ; −2 000 F : on doit de l'argent.
L'ascenseur Étage +3 : au-dessus du sol ; étage −1 : le parking en sous-sol.

🐴 L'image à garder

Un ascenseur : le rez-de-chaussée, c'est 0. En haut, les étages positifs ; au sous-sol, les négatifs.

Notation

📘 Comment on écrit un nombre relatif

  • Un nombre positif s'écrit avec + ou sans signe : +7 et 7, c'est le même nombre.
  • Un nombre négatif s'écrit toujours avec son signe − : −7. Si on oublie le signe, ce n'est plus le même nombre !
  • Dans un calcul, on met le nombre négatif entre parenthèses : 3 + (−7).

Les ensembles 𝔻, 𝔻⁺ et 𝔻⁻

NotationCe que c'est
𝔻Tous les nombres décimaux relatifs.
𝔻⁺Les nombres décimaux relatifs positifs.
𝔻⁻Les nombres décimaux relatifs négatifs.

Le signe ∈ se lit « appartient à ». Le signe ∉ se lit « n'appartient pas à ».

  • +3,5 ∈ 𝔻⁺ : +3,5 est positif.
  • −7 ∈ 𝔻⁻ : −7 est négatif.
  • −7 ∉ 𝔻⁺ : −7 n'est pas positif.
  • 0 ∈ 𝔻⁺ et 0 ∈ 𝔻⁻ : 0 est à la fois positif et négatif.

1. La distance à zéro

Le nombre sans son signe s'appelle la distance à zéro.

La distance à zéro de −18 est 18. Celle de +18 aussi.

2. Les nombres opposés

📘 Définition

Deux nombres sont opposés quand ils ont la même distance à zéro et des signes contraires.

L'opposé de +5 est −5. L'opposé de −3,2 est +3,2. L'opposé de 0 est 0.

3. Sur la droite graduée

On place les nombres relatifs sur une droite graduée : le 0 au milieu, les positifs à droite, les négatifs à gauche.

−4   −3   −2   −1   0   +1   +2   +3   +4

Le point d'abscisse −2 est 2 graduations à gauche du 0. Deux nombres opposés sont symétriques par rapport au 0.

4. Comparer deux nombres relatifs

📘 Trois règles

  • Un nombre négatif est toujours plus petit qu'un nombre positif : −100 < +1.
  • Entre deux positifs, le plus grand est celui qui a la plus grande distance à zéro : +3 < +8.
  • Entre deux négatifs, le plus grand est celui qui a la plus petite distance à zéro : −8 < −3 (−3 est plus près du zéro).

⚠️ Le piège

−18 est plus petit que −5 : il est plus à gauche. À −18 °C, il fait plus froid qu'à −5 °C.

À retenir

MotCe que ça veut dire
Nombre relatif Un nombre avec un signe + ou −. Ex : +4 ; −2,5.
Nombre positif Signe + (ou pas de signe). Il est à droite du 0. Ex : +7 = 7.
Nombre négatif Signe −. Il est à gauche du 0. Ex : −7.
Distance à zéro Le nombre sans son signe. La distance à zéro de −6 est 6.
Nombres opposés Même distance à zéro, signes contraires. +6 et −6 sont opposés.
Abscisse Le nombre qui repère un point sur la droite graduée.

🐴 En trois phrases

  • Le signe dit de quel côté du zéro on est.
  • La distance à zéro dit à quelle distance du zéro on est.
  • Plus un nombre est à gauche sur la droite graduée, plus il est petit.

Exercices

Cherche d'abord seule, ensuite ouvre la correction.

Exercice 1 — Positif ou négatif ?

Range ces nombres en deux listes : les positifs et les négatifs.

+4 ; −2,5 ; 17 ; −30 ; +0,8 ; −1

Voir la correction
  • Positifs : +4 ; 17 ; +0,8.
  • Négatifs : −2,5 ; −30 ; −1.

Exercice 2 — ∈ ou ∉ ?

Complète avec ∈ ou ∉.

  1. +6,2 … 𝔻⁺
  2. −9 … 𝔻⁺
  3. −0,5 … 𝔻⁻
  4. 12 … 𝔻⁻
  5. −4,7 … 𝔻
  6. 0 … 𝔻⁻
Voir la correction
  1. +6,2 ∈ 𝔻⁺
  2. −9 ∉ 𝔻⁺ : −9 est négatif.
  3. −0,5 ∈ 𝔻⁻
  4. 12 ∉ 𝔻⁻ : 12 est positif.
  5. −4,7 ∈ 𝔻
  6. 0 ∈ 𝔻⁻ : 0 est à la fois positif et négatif.

Exercice 3 — Distance à zéro et opposé

Pour chaque nombre, donne sa distance à zéro et son opposé.

  1. +9
  2. −4
  3. −2,5
  4. 13
Voir la correction
  1. Distance à zéro : 9. Opposé : −9.
  2. Distance à zéro : 4. Opposé : +4.
  3. Distance à zéro : 2,5. Opposé : +2,5.
  4. Distance à zéro : 13. Opposé : −13.

Exercice 4 — Compare

Complète avec < ou >.

  1. −5 … +2
  2. +7 … +3
  3. −8 … −3
  4. −1,5 … −2
  5. 0 … −6
Voir la correction
  1. −5 < +2 : un négatif est plus petit qu'un positif.
  2. +7 > +3
  3. −8 < −3 : −3 est plus près du zéro.
  4. −1,5 > −2 : −1,5 est plus près du zéro.
  5. 0 > −6

Exercice 5 — Le compte de Koffi

Écris chaque situation avec un nombre relatif.

  1. Koffi gagne 500 F.
  2. Koffi doit 300 F à Aya.
  3. Un poisson nage à 12 m sous la mer.
  4. Un oiseau vole à 40 m au-dessus de la mer.
Voir la correction
  1. +500
  2. −300
  3. −12
  4. +40
