║ Droites Parallèles

Leçon 5 - Parallélisme

Droites Parallèles

📘 Définition

Deux droites sont parallèles si elles n'ont aucun point commun ou si elles sont confondues.

Notation : d // d' (d est parallèle à d')

💡 Représentation

Les droites d et d' ne se coupent jamais

Elles restent toujours à la même distance l'une de l'autre

💡 Le codage du parallélisme

Sur une figure, on code deux droites parallèles avec le même petit chevron (une flèche) sur chacune d'elles.

💡 Des parallèles ne se coupent jamais

Même si on prolonge les droites d et d' très loin (en pointillés), l'écart entre elles reste le même : elles n'auront jamais de point commun.

✓ Propriétés

1. Deux droites parallèles ne se rencontrent jamais

2. Par un point hors d'une droite, il passe une seule parallèle à cette droite

3. Si d // d', alors d' // d (propriété symétrique)

4. Si d // d' et d' // d'', alors d // d'' (transitivité)

💡 À retenir :
• Parallèles = pas de point commun
• Symbole : //
• Les droites parallèles restent équidistantes

Construction de Droites Parallèles

Méthode 1 : Avec une équerre et une règle

🔧 Étapes de construction

1. Placer la règle le long de la droite d

2. Placer l'équerre contre la règle

3. Faire glisser l'équerre le long de la règle jusqu'au point A

4. Tracer la parallèle en suivant l'équerre

À la règle et à l'équerre : la règle sert de rail, l'équerre glisse dessus jusqu'au point A ; on trace alors la droite d' parallèle à d.

Méthode 2 : Avec un compas (méthode des perpendiculaires)

🔧 Étapes de construction

1. Tracer une perpendiculaire à d passant par A

2. Marquer un point B sur cette perpendiculaire

3. Tracer une perpendiculaire à (AB) passant par B

4. Cette dernière droite est parallèle à d

Rappel : Si deux droites sont perpendiculaires à une même droite, alors elles sont parallèles

Deux droites perpendiculaires à une même droite (AB) sont parallèles entre elles : c'est la méthode des deux perpendiculaires.

✓ Parallèle passant par un point

Par un point donné A, il existe une seule droite parallèle à une droite d donnée.

💡 À retenir :
• L'équerre + règle est la méthode la plus simple
• On peut aussi utiliser deux perpendiculaires successives
• Par un point, une seule parallèle à une droite donnée

🎯 Exercices

Exercice 1

Vrai ou Faux ?

  • a) Si d // d' et d' // d'', alors d // d''
  • b) Deux droites parallèles se coupent en un point à l'infini
  • c) Par un point, on peut tracer plusieurs parallèles à une droite

a) VRAI - Propriété de transitivité

b) FAUX - Les parallèles ne se coupent jamais

c) FAUX - Une seule parallèle par un point

Exercice 2

Complète avec les symboles corrects (// ou ⊥) :

  • a) Si d ⊥ d' et d' ⊥ d'', alors d ___ d''
  • b) Si d // d' et d' // d'', alors d ___ d''

a) d // d'' (deux droites perpendiculaires à une même droite sont parallèles)

b) d // d'' (transitivité du parallélisme)

💡 La figure à retenir : la transitivité

Si d est parallèle à d' et d' parallèle à d'', alors d est parallèle à d'' : les trois droites portent le même codage.

💡 Pour bien comprendre :
• Pratique en dessinant beaucoup de figures
• Utilise tes instruments de géométrie
• Vérifie toujours avec une règle graduée
